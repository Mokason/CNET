# Retained historical material

This directory holds reference material outside the active product path.
A retired source or instruction is not a supported build/deployment recipe.

The early competition fixture sources remain for provenance. Later frozen
benchmark generations stay under [benchmarks](../benchmarks/) with their
protocols/results; a newer generation does not invalidate an older failure.

[retired_python](retired_python/README.md) documents replaced Python behavior.
The documentation cleanup archive and per-path inventory are described in
[maintenance](../docs/MAINTENANCE.md). They preserve exact original bytes,
including implementation amendments and negative measurements.

Every future retirement must name a replacement or an explicit historical
purpose and preserve relevant consumers. Do not assume everything here is
safe to delete merely because active source discovery skips it.
