### Quality note

English path is live: `cce_gguf_tok` loads `tokenizer.ggml.tokens` + merges
from the GGUF, applies the Qwythos/Qwen chat template, encodes, generates,
and detokenizes with `skip_special`. Raw-id mode remains via
`CNET_QUALITY_RAW_IDS=1` or explicit id args.

Gemma-4-12B refused (KV-sharing arch geometry). Eco profile's SPARSE_KV
blocks qwen35 until host clears it and retries (fixed in mtk_host).

make gguf_tok quality_eval

./bin/test_gguf_tok hermes_wrappers/Qwythos-9B-*.gguf

CNET_GOV_PROFILE=balanced CNET_MAX_CTX=256 CNET_FOREST_NO_PERSIST=1 \
  CNET_QUALITY_PROMPT='What is 2+2? Answer with just the number.' \
  CNET_QUALITY_NO_THINK=1 \
  bin/cnet_quality_eval hermes_wrappers/Qwythos-9B-*.gguf 24
