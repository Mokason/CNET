# Three transformer-free capability measurements — 2026-09-11

Authorized: measure unfamiliar wording, acquisition of new procedures, and useful
response composition; integrate only improvements that preserve correctness,
abstention, speed, and resource requirements. No model endpoint calls.

Scope is the current VSA route/generation path and the previous structural
experiment, not the unrelated managed intent parser or all CNET learning systems.
No production behavior changes before evidence and a RED regression test.

Frozen protocol:
1. Language: baseline is the previous finite active/passive fact parser. Candidate
   adds compositional controlled-English normalization and role/polarity binding.
   Measure exact tuples on separately generated surface combinations, plus
   ambiguity, modality, role reversal, unsupported verbs, and injection negatives.
   Report genuinely unsupported constructions. Do not claim learned unrestricted
   semantics from a handwritten grammar. Runtime/memory compare like-for-like
   Python implementations; production int8 role collision remains a separate
   diagnostic.
2. Procedures: baseline is explicit example lookup (the VSA path has no procedure
   induction API); exact traversal with a supplied program is the oracle ceiling.
   Candidate enumerates relation programs of length 1–3, retaining every program
   consistent with independently verified demonstrations. Emit only when every
   remaining program agrees; empty/underdetermined version spaces refuse. Evaluate
   fresh graphs, repeated/reordered relations, conflicting examples, and programs
   outside the search language. Discovery time and retained memory count. This is
   bounded program synthesis, not arbitrary procedure acquisition.
3. Responses: baseline is the actual native n-gram generation function used by VSA
   capsules, given the same facts. Candidate renders an independently verified
   path as answer + evidence sentences, with no unsupported factual additions.
   Measure exact answer, evidence faithfulness, refusal, omitted steps, latency,
   input/setup memory, and output length. Fixed-format outputs do not establish
   open-ended writing. Certification flags, when used in fixtures, are synthetic.

Training/demonstration inputs come from deterministic independent graph tools,
never from CNET's own accepted answers. Freeze fixtures and source hashes before
scoring. Development and scored graph seeds differ. Do not tune to scored errors;
retain failure examples. Results are descriptive, with correlated procedural
fixtures explicitly disclosed.

Admission requires a like-for-like measured advantage and no correctness,
abstention, latency, or memory regression. If representation/integration costs
are not established, retain the candidate as an experiment, not production.
