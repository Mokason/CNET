# Verified task core — first end-to-end milestone

## Contract and sequence

The owner approved the sequence: verified experience, natural-language access,
useful certified compositions, then evidence-gated core training. Freshness and
conflict controls precede changing-source expansion. This implementation starts
with an offline-capable finite Unicode task, not arbitrary domain acquisition.

1. Persist each typed observation before one native call, retain its terminal
   outcome separately from independent evidence, and expose a bounded inbox.
   Observation alone must not create training demand. Duplicate delivery must
   not repeat a native call, including after an interrupted observation.
2. Allow explicit local-owner approval of a missed request against an imported
   external source hash. Approval and demand admission are one transaction.
   Never use a native answer as the training label or silently overwrite sources.
3. Resolve bounded natural-language forms to typed operations; ambiguous forms
   clarify and unsupported inputs abstain. The proposal carries no authority.
4. Rehearse a native miss, externally approved correction, existing canonical
   capsule acquisition, and offline success on a distinct phrasing. Retest
   existing capabilities and explicit out-of-domain refusal.
5. Extend measured task composition and core-selection experiments only on
   eligible independent evidence. Synthetic development traces never count as
   genuine usage or fresh confirmation. Existing allocator floors stay intact.

## Boundaries

Use the existing managed/native learning installation, LocalTableReference,
canonical capsule format, private filesystem validation and owner budgets.
Fresh learner installations receive a new explicit schema version; there is no
automatic migration or reset of old ledgers. Keep the existing live ingress and
frozen 72-hour installation untouched. No new cloud service, model provider,
arbitrary shell action, source crawler, or online learned allocator is enabled.

Independent evidence, proposed intent, native observation and owner approval
are different records. Source drift or conflicting native output fails closed.
Raw conversation text is not required in the native episode ledger. Record
synthetic/unreviewed origin explicitly; do not infer ordinary human use.

## Acceptance and evidence

Each slice records an executed RED before production changes, a GREEN after
implementation, and scoped regression/coverage evidence. Native end-to-end
checks must use actual capsule acquisition, not a fake dictionary answer.
Admission, duplicate, pause, source-change, mismatch, malformed-input and
interrupted-observation tests accompany successful paths.
