# Capsule branching test decision — 2026-09-13

Decision recorded after the isolated experiment: retain explicit bounded
branching as a supported experimental direction. The controlled checked join
and cache lifecycle pass; explicitly separated passage questions improve
under the local model judge. Production integration remains WITHHELD.

The experiment preserves existing single-input capsule admission and uses
the current exporter/importer. A Python operator checks two branch receipts;
it does not certify a multi-input capsule. The natural-language comparison
uses the existing VSA CLI independently of that operator and cache.

Before enabling a production path, measure an integrated request through
decomposition, branch routing, every branch's coverage check, result assembly
and cache admission. Preserve split identity, incompatible alternatives,
source evidence and refusal at every required branch. Keep the warmed local
target at p95 <= 1 ms and p99 <= 5 ms. Report storage-cold latency, concurrency
and resident bytes separately. Core-count limits alone cannot bound RAM for
arbitrarily sized capsules.

The next quality evaluation must include single questions, explicit compound
questions, ambiguous joins and unsupported dependencies, with held-out
content. Do not use these exposed 400 components as a new certification set,
lower a floor, or claim broader capability from arithmetic fixtures.
